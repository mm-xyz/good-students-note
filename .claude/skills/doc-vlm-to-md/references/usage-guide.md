# doc-vlm-to-md 參考：給 Claude 的 Phase 2 填寫指引

這份檔案給 Claude 在 Phase 2 填寫時參考（Mac / Windows 行為一致）。

## 一份檔、兩種空格，一次填完
`*_完整知識庫.md` 內有：
1. **章節摘要**（文字區，每章標題下）：依該節正文寫 2-4 句摘要 + 4-8 關鍵字。
2. **圖像解讀**（「📊 圖表與視覺內容」區，每張圖下）：用 Read 開該張 PNG，寫類型 + 2-3 句內容（含關鍵數據/結論）+ 4-8 檢索關鍵字。

## 填寫規則
- 只替換 placeholder 內容；圖片連結、標題、錨點不動。
- 繁體中文（台灣用語）；有數字就把關鍵數字寫出來。
- **掃描／圖像型 PDF**：圖像解讀不只描述，還要把整頁文字**逐字謄寫**到 placeholder 之後。
- 圖多時每批 5-10 張，分多輪填完。
- 看不清楚就說「此處看不清」，**不要編造**數據或內容。

## 路徑與資產
- `assets/` 必須與 `.md` 同層，Obsidian / RAG 才連得到圖。
- 圖檔命名：`fig_*`＝嵌入點陣圖；`chart_p*`＝向量圖表頁（v1.0.1 補抓）；`page_*`＝掃描整頁；`img_*`＝圖片資料夾。
