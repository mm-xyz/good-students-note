# ADR-2026-11-17-1328 — YouTube 網址路線：yt-dlp 為主、只用上傳者字幕、自動字幕與英文一律下載轉錄

- 識別碼：ADR-2026-11-17-1328
- 日期：2026-11-17（MM 確認這份 ADR 寫在本 repo）；決策本身 2026-11-13 到 2026-11-14 逐步定案，已實作於 studio-mcp main
- 狀態：已採納
- Lifov 卡：#1328（P5b）、#1267（主卡）
- 取代：ADR-2026-11-13-1267 決定 6（YouTube 先抓字幕，只有自動字幕就跑標點密度檢查）
- 相關：`docs/design/2026-11-12_studio-mcp-architecture.md` §20、§24、§25；studio-mcp 的 `skills/to-md/references/video.md`

## 背景

ADR-2026-11-13-1267 決定 6 把 YouTube 定為「字幕優先」：有上傳者字幕就用，只有自動字幕就先驗標點密度，不過門檻才下載轉錄，要看畫面的一律下載。實作 P5b 的過程中，這條路線又改了三處，改動散在卡片留言與設計文 §24、§25，沒有一份決策紀錄。本 ADR 補上，並標明取代決定 6。

## 決策

1. **下載工具用 yt-dlp，Downie 降為退路**（設計文 §25，2026-11-13 MM 交給 Fable 決定，取代同日稍早改用 Downie 的結論）。理由：ingest 要靠 exit code 判成敗，Downie 沒有完成訊號。Downie 退路尚未實作；只在 yt-dlp 失敗時由 agent 明確指定。
2. **只用上傳者字幕，不用自動字幕。** 取代決定 6 的「自動字幕先驗標點密度」：標點密度不等於品質，所以自動字幕一律不信，直接下載轉錄。
3. **下載轉錄的三種情況**：沒有上傳者字幕；`sub_lang` 指定的語言只有自動字幕有；帶了 `frames`（要看畫面就下載影片）。
4. **語言**：上傳者字幕預設中文優先，沒有中文才取第一個（含英文）；要別的語言在 `ingest` 的 `options` 帶 `sub_lang`。非中文照原語言處理，字數單位是詞數。
5. **`doctor` 檢查 yt-dlp 版本日期**：超過 60 天警告，缺少不變紅。
6. **失敗不重試**：私人、地區限制、網路失敗回 `REMOTE_FAILED`，回報 MM；其他網站與播放清單回 `GATE_FAILED`。

## 取捨

- 一律轉錄自動字幕比用字幕慢（一小時影片本地轉錄要十幾分鐘到數十分鐘），換來品質可預期。
- 中文字幕時間軸偏粗，已知取捨，記在 studio-mcp 文件。
- Downie 退路與其字幕語言設定未定，做退路時再補。

## 驗證

三支真實影片實跑：TED zh-TW 上傳者字幕、粵語自動字幕（改轉錄）、無字幕走本機 whisper；驗收 Claude opus 兩輪，第 2 輪 PASS（#1328 留言 2026-11-14）。
