# ADR-2026-11-12-1267 — studio MCP：獨立 repo、管線搬遷、session 封存、skill 收成四顆

- 識別碼：ADR-2026-11-12-1267
- 日期：2026-11-12
- 狀態：已採納（MM 拍板）
- Lifov 卡：#1267（併 #1175，已 discard）
- 相關：`docs/design/2026-11-12_studio-mcp-architecture.md`（全文）；ADR 0001、ADR-2026-09-11-session-paths-single-source；ai-reels ADR 0002

## 背景

知識線（good-student）、剪輯線（podcast-cut）、短影音線（ai-reels）的腳本散在兩個 repo 與 8 顆 skill。agent 每次要先找路徑與參數，輸出是給人讀的文字，`cut.py` 會停下來問人。

## 決定

1. **獨立 repo `studio-mcp`**，私有，不對外發布。
2. **管線程式搬進新 repo**（good-students-note 的 `scripts/`、`SRT/qaqc_srt.py`、`dict/`、`prompts/`、`shared-material/`、ADR；ai-reels 的 `scripts/`、`template/`）。不帶 git 歷史，以兩個舊 repo 的 tag `pre-studio-split` 為準。先搬家、後改裝：搬的那一期不改行為。
3. **過去的 session 全部封存**在 `good-students-note/sessions/`，只讀。找得到、可當短影音線的輸入，不能初剪或出片。要重剪就用 `session adopt` 搬進新 repo。EP22 已上架，一併封存。
4. **命令列是合約，MCP 是轉接頭**。搬過去的腳本保留原樣，各加 `--json`；MCP server 不匯入管線程式，一律開子行程。
5. **長工作走 job**，紀錄放 repo 的 `_local/jobs/`，不放 session 裡。
6. **出片不碰雲端**。推雲端獨立成 `publish_version`，內容是 rclone 加設定檔裡的目的路徑。覆蓋雲端 cutplan 要另外明示。
7. **skill 從 8 顆收成 4 顆**：to-md、good-student、podcast-cut、reel-cut。skill 只寫何時用、順序、判斷點；路徑與參數交給工具；跨工具的規矩放 server 的 `instructions`。
8. **不給外部使用者**：Windows 安裝包、Claude Desktop 用法、installer 目錄不搬。
9. **astro-chunking 封存**；它獨有的受控詞彙、目錄結構、ASR 錯字對照先搬進 good-student 的 references。
10. **good-student-notes 的身份視角註解筆記不搬**（124 個 session 無一產出）；清理（`cleaned.srt`）保留並成為 to-md 的標準終點。

## 被否決的選項

- 放在 good-students-note 裡加一層：MM 要獨立 repo。
- 管線留原地、新 repo 只放轉接頭：三個 repo 的版本會漂；MM 選擇搬。
- 收成單一入口、舊腳本不能直接跑：要重寫所有 ADR 與測試裡的指令，對經 MCP 呼叫的 agent 沒有差別。
- 出片時順手寫 Drive 掛載路徑：會撞上 MM 開著的編輯器（2026-10-03、10-05 兩次事故），且 tmux 底下被 macOS 權限擋。

## 尚未決定
