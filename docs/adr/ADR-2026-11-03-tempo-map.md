# ADR-2026-11-03-tempo-map — 語速分段變速：`## ⏩ 起-迄 倍率`

- 識別碼：ADR-2026-11-03-tempo-map
- 日期：2026-11-03
- 狀態：已採納
- 相關：卡 #1174；ADR-2026-11-03-bgm-loudness-normalize

## 脈絡

EP22 意見「整集偏慢、偏沉悶」，想前半調快、後半維持原速。`--tempo`／`⚙ tempo=` 只有全集單一值。

## 決定

1. cutplan 新增結構行 `## ⏩ 起-迄 倍率`（原始時間軸，與 block 時間碼同一軸；迄可省略＝到結尾；
   倍率前必須有空白）。例：`## ⏩ 00:00-10:00 1.05`、`## ⏩ 10:00- 1.0`。
2. 語音 segment 在變速界線處切開，每片帶自己的 `tempo`；沒落在任何 ⏩ 區間的用全域 tempo。
   配樂走 overlay 不變速（維持既有行為）。
3. `cut_map.json` 的 ranges 逐段記 `tempo`；`src_to_dst`（render_cut、diff_clips）、
   `build_timeline`、copy_prompt_build 都優先用該段 tempo。同時修掉 `src_to_dst` 過去沒除 tempo 的舊誤差。
4. 格式寫錯（缺空白、`10:00-1.0`）、區間重疊、倍率不在 0.5–2.0 一律報錯，不靜默吃掉。

## 後果

- 界線處兩片來源連續、倍率不同，接縫走既有 40ms 交疊，成品比理論短約 40ms／界線。
- 舊的單一 `tempo=` 寫法完全相容。
- 編輯器只認 block 行；⏩ 行由 agent 或手動寫在 cutplan，編輯器的行數護欄需把它當結構行（未實作，尚未開放編輯器插入）。
