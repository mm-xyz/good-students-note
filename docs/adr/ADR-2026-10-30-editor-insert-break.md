# ADR-2026-10-30-editor-insert-break — cutplan 編輯器開第二個口：插入間奏 `## 🎵 break`

- 識別碼：ADR-2026-10-30-editor-insert-break
- 日期：2026-10-30
- 狀態：已採納
- 相關：ADR-2026-09-10-roomtone-insert（第一個口）、ADR-2026-09-10-cutplan-template（break 參數取樣板）

## 脈絡

EP22 人審時要在編輯器直接插間奏，原本只能由 agent 手動改檔，而改檔必須等 MM 關掉編輯器。
留白那次定下的條件：既然人可以插，就必須**看得到、刪得掉**，否則手機上插錯沒有退路。

## 決定

1. 每張 block 卡片多一顆「＋ 之後插間奏」，插入**整行就是** `## 🎵 break` 的一行；參數取樣板，不給自由輸入。
2. 該行顯示為「🎵 間奏」並帶刪除鈕、可復原。
3. 伺服端護欄（`findIllegalEdit`）比對前，兩邊都先拿掉 `## 🔇` 與單獨一行的 `## 🎵 break`，其餘照舊；
   帶參數的 break、opening、ending 仍唯讀（插了會被「行數不一致」擋下）。

## 後果

- 護欄過去一律比行數，連留白都擋（EP22 實測「行數不一致 2277 → 2278」），本案與留白一併修正。
- 編輯器可增刪的結構行共兩種；要開第三個口，先確認「看得到、刪得掉、參數不需自由輸入」三件事成立。
