## 這批報告裡真正改變決策的三件事

1. **逐軌 ASR 不可當出片文字**（04、05 都獨立指出，實測佐證）：Mars 直錄軌在
   295–323 秒陷入「嘗」重複迴圈，而 Sarah／KIN 軌的**串音** ASR 反而轉出了
   Mars 原句。canonical 文字改取混音逐字稿，逐軌波形只決定歸屬與靜音。
2. **「沒有任何 block 覆蓋的軌 ＝ 預設靜音」**（05）：附和偵測的召回率只影響
   「人看不看得見、能不能撈回來」，不影響「消不消得掉」。這句話把問題整個翻面，
   讓門檻調校從關鍵路徑降級。
3. **音色跳變不能靠零星關麥解決**（05）：要用整集一致的 activity mask
   （主要講者 0dB／非主要軌常態 −24～−30dB）＋ room-tone bed，只在偶發事件
   突然關一軌會改變串音的相位組合，產生底噪抽動。

## 對照組的實際效益

luna 版與 Opus 5 版同規格同起點（HEAD `6272edf`）並行實作，最終取 Opus 版：

| | luna max | Opus 5 |
| :--- | ---: | ---: |
| commits | 0 | 3 |
| 人審資產遷移 | 丟 48 處刪除線、5 個剪除 | 零遺失 |
| 長度 vs 混音版 | −162.5s（−8.9%） | −2.5s（−0.14%） |
| LRA | 7.4 → 16.7 LU | 7.4 → 7.8 LU |
| D5 activity mask | 未實作 | 已實作 |

但 luna 的評審（04）抓到主線兩個真缺陷：死參數 `--excess`、以及
**同軌 block 重疊 957 組**（會讓 atomic cell 出現矛盾勾選狀態）。
對照組的價值在此——不在誰的實作被採用。
