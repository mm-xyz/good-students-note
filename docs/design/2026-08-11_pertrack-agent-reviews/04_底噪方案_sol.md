# 分軌線底噪方案評審

## 結論

### 1．降底噪的處置順序

採用**逐軌、進 speech bus 前的軟式 downward expander**，不在 speech bus 上做 gate，也不讓 gate 先於 cells／人審決定內容去留。每軌先套相同的 100Hz high-pass，再做 expander，之後才是 static gain、共同 atrim、cells 增益包絡、pan 與混成；bus 端只保留既有的保守 dynaudnorm。門檻以該軌 high-pass 後、可確定沒有本人出聲的負樣本計算：開門取底噪 P99.5＋6dB，關門取 P99.5＋3dB，配 50ms lookahead、約 180ms hangover、約 220ms release、4：1 ratio 與最多 18dB 衰減，整集自動算一次，不逐段漂移。

gate 只負責降低空隙噪聲，**不得取得剪輯決定權**：已勾選的語音 block、已勾選的「非詞彙出聲」及其前後保護區都要強制開門，因此氣音、笑聲尾巴與人審要留的聲音不會被門檻否決。100Hz high-pass 是低風險預設；`afftdn` 的收益只有 1～3dB，卻有水聲／金屬感風險，不應進第一版預設鏈。

### 2．句間短空隙

保留「≤0.9s 不刪時間」的原則，但取消「前一位講者整段 0dB 開麥」：**時間橋接與麥克風橋接必須拆開**。前一軌只保留約 180ms hangover，下一軌提前約 50ms 開門；兩者中間若仍有空白，就退到固定底床而不是繼續播前一支麥克風的 live noise。短到小於 hangover＋lookahead 的換氣縫自然仍會整段開著，所以語氣、呼吸與笑聲尾巴不會被切碎；較長空隙仍保有原長，聽感不會變成連珠炮。

超過 0.9s 的無主停頓仍沿用現行收緊到 0.6s 的規則，勾選 G 列則繼續視為人審明確要求保留原聲的例外。這一改動直接針對 P10 改善不足的來源：不是再把最深靜音壓低，而是避免 0.2～0.9s 的空隙始終維持 KEEP 電平。

### 3．MM 的單一主軌承載空白

**部分採用其目的，不採用 live 主軌整集承載空白的做法。** 空白統一使用「單一 anchor 軌取樣出的 room-tone bed」，可得到 MM 要的固定音色，又不會把該軌偶發的呼吸、碰桌、串音或電平波動帶進所有空白。anchor 每集自動選一次：比較 high-pass 與預計 static gain 後的安靜窗，以 P90 最低且窗間變異最小者勝出，整集固定不換；MIC1 只有在量測勝出時才會成為 anchor。

現行「三軌相加取樣」的 room-tone bed 應由這個單軌 bed **取代**，不能兩層並存；也不另開 live anchor mic。底床目標要以最終 loudnorm 後的輸出座標校準，維持在殘餘句間噪聲下至少 10～15dB，否則 gate 成功後，room tone 反而會成為新的可聞地板。

### 4．表格＋select 的人審介面

**不值得把 1811 列全面改成三軌表格。** 它會把 MM 的工作從「判斷內容留不留」膨脹成逐格做混音選軌，閱讀量接近三倍，但高信心的單人語音並沒有值得人工重選的資訊。表格只會把底噪的自動處理責任轉嫁給人，並增加漏選、互斥選錯與既有人審資產無法往返的風險。

相同控制力可留在現有格式：一般 block 由支配／cells 自動歸軌；只有歸屬不確定、真正 overlap、非詞彙出聲或能量異常的時間點，才把同時間的候選軌相鄰列出，仍用既有 `- [x]`／`- [ ]` 決定。能量差、噪聲門檻與信心只作旁證，不改 canonical 文字，MM 只審例外、不必掃三軌矩陣。

### 5．不要動的紅線

三條紅線全部維持：cutplan 的勾選、刪除線、G 列與既有 block 文字格式不變；新處理只在 cutplan 有 `tracks` 且走 `line=pertrack` 時生效；沒有 `tracks` 的 EP15 類素材仍走原本 mixdown filter graph。底噪統計、high-pass、expander、anchor 選擇與驗收都用本地音訊運算，不引入雲端 API，也不讓自動 gate 覆蓋任何人審 KEEP／SILENT 決定。

## 必要的實作切點

1. **把 cells 留作控制平面。** 先完成 atomic cells、時間保留與人審狀態，再把「強制開門區」「可衰減空隙」「明確靜音」交給逐軌 expander；不能先盲 gate 再拿處理後能量反推 block，否則會形成自我強化的漏音。
2. **逐軌濾波必須保持連續狀態。** high-pass／expander 不可在每個 cell、每個 atrim 或每個 30 秒讀取 chunk 重置，否則每個邊界都會重新開門或產生 pumping；應在來源時間軸連續處理，或讓 detector 狀態跨 chunk 延續，再套共同 atrim。
3. **改寫短空隙的 mask 語義。** 現行 `apply_mask` 把 ≤0.9s 的全 DUCK 區升成前一軌 KEEP，應改為只保留共同時間軸，麥克風端由 hangover／lookahead 與 anchor bed 承接；`resolve_time` 的停頓長度政策本身可保留。
4. **room tone 只留一個來源。** 從 anchor 軌多個不相鄰的乾淨片段取樣，以平滑交疊避免可辨識循環；輸出時記錄選中軌、取樣窗、原始與預估成品底床，讓每集可重現。
5. **門檻要有可信度守門。** 負樣本必須排除本人 speech／已勾選非詞彙事件及明顯碰撞聲；若乾淨樣本不足，就停用該軌 expander、只套 high-pass 與既有 activity mask，不能用污染過的 P99.5 猜門檻。
6. **驗收看最終成品，不只看 gate 前。** 每集至少量最終 loudnorm 後的底噪 P1、P10、講話 P90、LRA、true peak，並抽聽低音量字頭、笑聲／氣音尾巴、換手、0.2～0.9s 空隙與長停頓；目標應以 P10 至少再降約 6dB、語音 P90 變化不超過 0.5dB，且受保護事件零截斷為第一道驗收線。

## 主要風險

- **P99.5 樣本污染**：若把呼吸或遠端串音當底噪，門檻會過高；因此 P99.5 只能用高信心負樣本，不能直接對整集「低能量窗」計算。
- **expander 呼吸感**：衰減太深或 release 太短會讓底噪隨音節抽動；第一版限制為軟膝、最多 18dB，並以人審 block 強制開門，比追求數位靜音安全。
- **相位與音色**：三軌 high-pass 應使用同一截止頻率與型式，避免各軌不同相位響應在混成時改變串音音色；逐軌差異化 EQ 不應與本次底噪修正一起擴張。
- **底床反客為主**：loudnorm 會把前端所有殘餘一起抬高，anchor bed 必須按最終輸出回算；不能只看 speech bus 上的 −60dBFS 就認定成品一定聽不到。
- **評審介面膨脹**：若例外候選仍多到接近全表，代表歸屬／偵測門檻失效，應修自動判斷，不應用表格要求 MM 吸收演算法的不確定性。
